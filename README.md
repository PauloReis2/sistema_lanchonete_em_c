# Caixa de Lanchonete em C

Mini-sistema de terminal desenvolvido em C para praticar a lógica de programação na faculdade.

## Funcionalidades
- Cadastro de pedidos (código e valor).
- Listagem dos pedidos em formato de tabela simples.
- Cálculo automático do valor total das vendas.
- Validação para não estourar o limite máximo de registros.
