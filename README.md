
#Sistema de Caixa de Lanchonete em C

Mini-sistema desenvolvido com o objetivo de praticar a lógica de programação, manipulação de dados e estruturas em C durante a faculdade.

##Funcionalidades
- **Registrar Pedido:** Permite cadastrar o código e o valor de novos pedidos.
- **Listar Pedidos:** Mostra todos os pedidos registrados até o momento em formato de tabela e calcula automaticamente o **valor total das vendas**.
- **Controle de Limite:** Impede cadastros além do limite máximo estipulado.

##Conceitos aplicados
- struct para modelagem de dados.
- Vetores (Arrays) para armazenamento em memória.
- Laços de repetição (do-while e for).
- Estruturas de decisão (switch-case e if-else).
